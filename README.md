# Mindora

Online psychologist and client matching platform developed with modern web technologies.

## Features

- Psychologist & client matching system
- Admin management panel
- Authentication & authorization
- Payment infrastructure
- Email notification system
- User management
- Responsive modern UI

## Technologies

- Next.js
- TypeScript
- Supabase
- PostgreSQL
- Tailwind CSS
- Vercel

## Purpose

Mindora aims to simplify access to psychological support through a modern, scalable and user-friendly platform.

## Status

Active development and deployment process continues.
